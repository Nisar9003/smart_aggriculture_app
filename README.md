# 🌾 Smart Agriculture Assistant

A Flutter mobile app that helps farmers manage their crops, check live weather, get soil-aware irrigation/fertilizer schedules, and get pest/disease spray advice — built for Pakistani farmers, with a Roman Urdu interface.

> Kisano ke liye Digital Fasal, Mausam aur Zameen ka Rehnuma.

---

## ✨ Features

- **📱 Phone Number Login** — Firebase Authentication (OTP-based)
- **☁️ Live Weather** — current conditions + 5-day forecast (OpenWeatherMap API), based on the farmer's real GPS location
- **🌱 Crop Management** — add a crop with its sowing date, area (acres), and location
- **🧪 Soil Data** — automatic soil type + pH lookup for the farmer's field (SoilGrids / ISRIC API, free & no key required)
- **🗓️ Smart Roadmap** — a per-crop irrigation & fertilizer schedule that adjusts based on:
  - the specific crop (Wheat, Rice, Cotton, Sugarcane, Maize, Vegetables each have their own realistic schedule)
  - soil type (sandy soil waters sooner/more often, clay soil less often)
  - soil pH (adds a lime/gypsum treatment task if very acidic/alkaline)
  - live weather forecast (warns if rain is expected on a planned watering day)
- **🐛 Pest & Disease Advisory** — searchable list of common pests/diseases per crop with recommended pesticide & dosage, plus a live Wikipedia-based fallback search for anything not in the local list
- **🗑️ Delete Crops** — swipe-to-delete on the home screen, or delete from the crop detail screen
- **☁️ Cloud Sync** — all crop data is stored in Cloud Firestore in real time; works across sessions
- **🧪 Demo Mode** — the whole app also runs fully offline with local, in-memory data if Firebase hasn't been configured yet — useful for quickly demoing the UI without any backend setup

## 🏗️ Tech Stack

| Layer | Technology |
|---|---|
| Mobile App | Flutter (Dart) |
| Authentication | Firebase Authentication (Phone/OTP) |
| Database | Cloud Firestore |
| Weather Data | [OpenWeatherMap API](https://openweathermap.org/api) |

## 📂 Project Structure

```
lib/
  main.dart                     -> app entry point, Firebase init
  firebase_options.dart         -> Firebase config (generated by FlutterFire CLI)
  theme/app_theme.dart          -> colors, fonts, styling
  models/                       -> Crop, RoadmapTask data models
  data/
    app_data.dart                 -> remaining mock data (farmer profile)
    pest_advisory_data.dart       -> pest/disease + pesticide knowledge base
  services/
    auth_service.dart             -> phone OTP login (Firebase + demo fallback)
    crop_repository.dart          -> Firestore CRUD + smart roadmap generator
    weather_service.dart          -> OpenWeatherMap API calls
    weather_repository.dart       -> shared/cached weather state
    location_service.dart         -> GPS location
    soil_service.dart             -> SoilGrids API calls
    web_search_service.dart       -> Wikipedia fallback search
  screens/                      -> all app screens
  widgets/                      -> reusable UI components (cards, tiles)
```

## 🚀 Getting Started

### 1. Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
- A free [Firebase project](https://console.firebase.google.com) (optional — app runs in Demo Mode without it)
- A free [OpenWeatherMap API key](https://openweathermap.org/api) (optional — weather screen shows an error without it, rest of the app still works)

### 2. Clone & install dependencies

```bash
git clone <this-repo-url>
cd smart_agri_app
flutter pub get
```

### 3. Configure Firebase (optional, for real data persistence)

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

This generates a real `lib/firebase_options.dart` for your own Firebase project. In Firebase Console, enable:
- **Authentication → Sign-in method → Phone**
- **Firestore Database** (start in test mode for development)

> Without this step, the app automatically runs in **Demo Mode** — crops are kept in memory instead of the cloud, and login accepts OTP code `123456` or `000000`.

### 4. Add your own Weather API key

Open `lib/services/weather_service.dart` and replace the API key with your own free key from OpenWeatherMap:

```dart
static const _apiKey = 'YOUR_OPENWEATHERMAP_API_KEY_HERE';
```


### 5. Run the app

```bash
flutter run -d chrome     # quickest way to test, in the browser
flutter run                # on a connected Android device/emulator
```
